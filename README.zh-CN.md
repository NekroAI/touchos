# Nekro TouchOS

[English](README.md)

**触控板上的可视化快捷面板。** 一根手指按住触控板角落唤起面板，另一根手指在触控板上按位置选择槽位，抬起即执行动作。看着选，不用记手势。

> **状态：早期开发中（M0 技术原型），暂无可安装版本。**

## 用法设想

1. 拇指在触控板左下角静止按住：光标冻结，面板淡入。
2. 另一根手指在触控板上移动：位置与面板一一对应，高亮所在槽位。
3. 抬起这根手指执行槽位动作——快捷键、打开应用或网址、Shell 命令、AppleScript、快捷指令、系统控制；先抬起拇指则取消。

除此之外，TouchOS 只旁听，不改变触控板、鼠标、键盘的任何行为。

## 系统要求

macOS 14 及以上；内置力度触控板，或妙控板（第二代及以后）。

## 隐私

TouchOS 通过 macOS 私有框架读取触控板原始触点，仅在内存中处理，从不记录、存储或上传。
