# Documentation

Design documents are written in Chinese. Short English summaries are given below.

| Document | Summary |
|---|---|
| [srs.md](srs.md) | Software requirements specification — the single source of truth for implementation: architecture, the session state machine (T1–T21), algorithms, event tap policy, overlay, actions, config format, acceptance cases (AC-1–AC-20) and the task plan (K1–K16). |
| [decisions.md](decisions.md) | Decision log — every decision with its reasoning (including amendments to the SRS), open questions and unverified assumptions. **Read this before proposing changes.** |
| [research.md](research.md) | Background: competitive analysis (BetterAndBetter), terminology, technical feasibility and usability risks. |
| [brand.md](brand.md) | Brand guidelines: the "stroke" mark, colors, logo and menu bar icon usage. |
| [m0-report.md](m0-report.md) | M0 prototype report: measured frame rate, latency and the acceptance results behind the M0 gate. |
