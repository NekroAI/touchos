# 品牌规范

决定见 `decisions.md` D43。生成脚本与图标原图在 `tools/icon/`。

## 标志「笔触」

一笔写完的 T：横笔由细到粗上扬，竖笔带弧度收成笔锋，落进一个触点。写出的是"手指落下、光被带动"的那一下。

- 文件：`assets/mark.svg`（矢量）、`assets/logo-dark.png` 与 `assets/logo-light.png`（横排，透明底，分别用于深色、浅色背景）、`assets/icon-128.png`（README）。
- 竖笔与触点必须连在一起。分开时整个图形读作感叹号。
- 菜单栏用单色模板图（18 pt，`BrandMark.swift`）；异常状态在右下角加橙点，不换图形。

## 颜色

| 用途 | 值 |
|---|---|
| 笔画渐变（深色底） | `#FFC27A` → `#FF5C7A` → `#9A4DFF` |
| 笔画渐变（浅色底） | `#E8743A` → `#E0305F` → `#7A35E0` |
| 图标底色 | `#2A1638` → `#0B0812` |
| 触点 | `#FFFFFF`，光晕 `#FF5C7A` |

浮层的强调色不是品牌色：默认跟随系统，由用户自选。

## 字标

Inter Semibold（SIL OFL 1.1）：`TouchOS` 字距略紧，上方小字 `NEKRO` 字距放宽。

## 图标网格

1024 画布，主体 824 × 824，圆角 185，符合 macOS 图标规范，系统不会再套灰底。
